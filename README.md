🏦 Python ATM Simulation

This is a simple console-based ATM application developed using Python.
It allows a user to create an account, log in using a PIN, and perform basic banking operations.

✨ Features

Create a new account

Login using 4-digit PIN

View account details

Check balance

Deposit money

Withdraw money

Exit the application safely

🛠️ Technologies Used

Python 3

Concepts used:

Variables

while loop

match-case

Conditional statements

User input/output

📂 Project Structure
atm-program/
│
├── atm.py        # Main Python program
└── README.md     # Project documentation

▶️ How to Run the Program

Make sure Python 3.10 or above is installed (required for match-case)

Clone this repository:

git clone https://github.com/your-username/atm-program.git


Navigate to the project folder:

cd atm-program


Run the program:

python atm.py

🧪 Sample Operations

Create an account by entering name, password, account number, and PIN

Login using the PIN

Deposit or withdraw money

Check current balance

⚠️ Limitations

Supports only one user at a time

Data is not stored permanently (no database/file handling)

PIN is not encrypted
